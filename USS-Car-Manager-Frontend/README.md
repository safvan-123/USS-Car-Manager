# USS Car Manager frontend 2.1

Responsive React/Vite frontend for the supplied USS Car Manager v2 API.

Start with **[START-HERE.md](START-HERE.md)** for local setup, deployment, dashboard definitions and allocation repair instructions.

```sh
npm ci
npm run dev
```

Verification:

```sh
npm test
npm run lint
npm run build
```

No backend files or production credentials are included. No database migration is performed by this frontend.
